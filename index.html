本地处理视频，按你的流程完成字幕与压缩

MediaSculpt（影刻）是面向 Windows 的本地视频处理工作台：先识别片源和字幕，再由你选择字幕、无损封装或压缩步骤。AI 只作为可选增强，不替用户自动决定处理方式。

它做什么

从普通视频到 DVD／蓝光，影刻把分析、字幕、无损封装和压缩放在同一条可确认的工作流里。

核心

明确选择后开始

不需要命令行。加载片源后，用户明确选择 Remux、字幕或压缩步骤及相关参数，再确认任务；软件不会预先替你勾选处理模式。

核心

本地字幕生成

已有软字幕优先提取，图形字幕尝试 OCR，没有可用字幕才使用 Whisper。工具和模型安装完成后可离线处理；首次准备工具或模型需要联网。

核心

AI 双语字幕

翻译需要联网和用户配置的 AI 服务，通常只发送字幕文字；使用视觉模型进行图形字幕 OCR 时，可能还会发送字幕图像。第三方调用费用由用户承担。

核心

双语排版可调

双语字幕可按布局设置上下顺序、位置和字号；ASS 更适合表达字号差异，导出前可在本地预览。

顺手也能做

压缩与老碟处理

普通视频和光盘内容可使用 HandBrake 重新编码；DVD／蓝光可尝试无损封装（Remux，不重新编码）。复杂片源仍需实际验证。

顺手也能做

可组合的归档链路

可以把分析、字幕、Remux 和压缩串成任务链；每一步独立记录输入、输出和错误，最终播放兼容性仍取决于源文件、容器和编码。

它是怎么做的

本地处理为主；首次准备工具、在线翻译和部分视觉 OCR 会联网。

1

识别字幕来源

软字幕优先提取，图形字幕尝试 OCR，没有可用字幕才提取音轨运行 Whisper。工具和模型安装完成后，处理可在本机完成。

2

按需使用网络服务

翻译通常发送字幕文字；视觉 OCR 可能发送字幕图像。视频文件默认不上传，但第三方服务的处理和留存规则由其服务条款决定。

3

写回并检查输出

可导出 SRT/ASS 双语软字幕，或选择压制进视频。输出是否能被特定播放器直接播放，仍取决于容器、编码和源文件。

常见问题

视频会上传吗？

视频和光盘内容默认只在本机读取、处理和写回。在线翻译会发送字幕文字；视觉 OCR 可能发送字幕图像到你配置的服务。

现在支持哪些系统？

当前公开测试安装包面向 Windows 10/11、64 位系统。其他系统没有对应的正式安装包，不应按 Windows 安装包的兼容性推断。

为什么第一次处理会比较慢？

首次使用 Whisper 或 OCR 时需要安装工具并下载模型；之后会使用本机缓存。语音识别和复杂光盘分析本身也会随时长增长。

为什么有字幕时仍可能进入语音识别？

软件会先判断字幕轨是否为可用软字幕，再尝试图形字幕 OCR；轨道不可读、工具缺失或覆盖不完整时，才可能回退到 Whisper。请以任务日志中的字幕来源为准。

预览或输出播放失败怎么办？

浏览器和播放器对容器、编码、字幕烧录的支持不同。请先检查任务输出和诊断日志，并在反馈中附上源文件类型、编码和错误码。

遇到问题怎么反馈？

请在 GitHub 仓库提交 Issue，并附上任务类型、系统版本和诊断日志，方便定位问题。

测试版会收费吗？

公开测试期间暂不收取软件订阅费；你配置的第三方 AI、翻译或网络服务可能按其规则收费，正式版授权方式另行公布。
