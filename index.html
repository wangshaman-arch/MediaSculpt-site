它做什么

从普通视频到 DVD／蓝光，影刻把压缩、无损提取、字幕处理和输出整理在同一条工作流里。

核心

一键出稿

不需要命令行，不需要调参数，不需要先把视频转码。加载视频，按一次回车。

核心

中文字幕，全离线

中文视频生成中文字幕，全程在本机完成——不需要联网，也不需要 API Key。视频文件始终不上传。

核心

AI 双语字幕

需要翻译时才联网，而且只发送字幕文字。自己填 API Key，按自己的用量付费，不用为软件另付订阅费。

核心

双语排版可调

双语字幕上下分栏，位置和字号都能调，导出前就能看到效果。

视频压缩；老 DVD / 蓝光的无损提取（remux，不重新编码，画质零损失）；以及光碟内容压缩。

外语老碟 → 无损提取 → 生成或翻译双语字幕 → 按需压缩到合适体积，得到一个直接能看的文件。

为什么第一行这么快？ 因为视频已经带了字幕轨，不需要做语音识别。 需要语音识别的场景会慢得多，具体取决于视频时长和你的硬件——这一点我们不含糊过去。 翻译速度取决于你选择的模型与 API 速率，软件会自动控制并发，并在遇到限流时降速重试。

另外，语音识别需要额外下载一个模型 —— 安装包不含它（体积太大），软件会在你第一次需要时提示下载。

它是怎么做的

三步，中间只有一步需要联网。

1

本地提取字幕

软字幕直接解析；图形字幕做 OCR；没有字幕的就跑语音识别。全部在本机完成，不联网。

2

需要翻译时才联网

只把字幕文字发给你自己配置的 AI 服务，用于生成双语字幕。视频文件本身不出本机。

3

本地写回输出

导出双语软字幕（srt / ass），或直接压制进视频。排版的位置与字号都可以调整。

常见问题

视频会上传吗？

不会。视频和光盘内容只在本机读取、处理和写回。使用 AI 翻译时，软件只发送字幕文字到你自己配置的服务。

现在支持哪些系统？

当前公开测试版优先支持 Windows 10 及以上、64 位系统。macOS 版本会在完成适配后单独发布。

为什么第一次处理会比较慢？

语音识别需要按需下载 Whisper 模型；首次安装和模型准备完成后，后续任务会直接使用本机缓存。

遇到问题怎么反馈？

请在 GitHub 仓库提交 Issue，并附上任务类型、系统版本和诊断日志，方便定位问题。
