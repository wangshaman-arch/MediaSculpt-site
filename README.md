# MediaSculpt（影刻）

MediaSculpt 是面向 Windows 的本地视频处理工作台，目标是把光盘分析、视频无损提取、压缩、字幕处理和资料整理放在一条可核对的工作流中。它优先在本机读取和处理视频、DVD、蓝光目录及字幕文件；网络服务和 AI 能力均为可选增强。

## 主要能力

- 分析普通视频、DVD `VIDEO_TS` 和蓝光目录，查看标题、播放列表、时长、章节、音频和字幕流。
- 按用户确认执行无损提取（Remux，不重新编码）或 HandBrake 高质量压缩。
- 提取内置软字幕；对 PGS、VobSub 等图形字幕按需使用 OCR 转为可编辑字幕。
- 使用本地 Whisper 从音轨生成字幕；再导出 SRT/ASS、生成双语字幕或按选择压制进视频。
- 通过可配置的翻译服务进行字幕翻译；也支持按需准备本地翻译工具。
- 记录工具版本、输入输出、处理参数、进度和错误，便于复现与排查。
- 支持单独执行扫描、字幕、无损提取和压缩步骤，也支持组合成工作流。

## 推荐使用流程

1. 打开软件并检查“设置 → 工具”，确认 FFmpeg、FFprobe 和 HandBrakeCLI 可用。
2. 选择视频文件、DVD `VIDEO_TS` 目录或蓝光目录，先执行分析并核对标题、时长、流轨和源文件路径。
3. 有可用软字幕时优先提取；图形字幕使用 OCR；没有可用字幕时再使用 Whisper。
4. 明确选择无损提取、压缩、字幕导出或翻译步骤，并检查输出目录。
5. 任务完成后核对输出文件大小、时长、时间码、音视频流和字幕，再删除或移动源文件。

## 工具链说明

FFprobe/FFmpeg 负责媒体探测、流选择、字幕提取和无损封装；HandBrakeCLI 负责重新编码压缩；Whisper 负责从音频识别对白；RapidOCR/Tesseract 等工具负责图形字幕 OCR；翻译工具或服务负责字幕翻译。不同工具对不规范光盘的识别结果可能不同，因此软件会保留分析结果和任务日志，输出前应以最终选择和日志为准。

## 能力边界

复杂 DVD 可能包含多个相近时长标题、菜单片段、重复播放列表或损坏的 IFO/VOB；蓝光可能存在缺失、加密或无效的播放列表引用。软件会尽量筛选有效标题，但不能把不完整或受保护的片源保证为可播放输出。加密蓝光还需要用户自行准备合法的解密环境和密钥，基础安装包不承诺内置商业解密能力。

浏览器预览能力受浏览器对容器、编码、隔行视频和字幕格式的支持影响；预览失败不等于任务输出失败。请以任务输出文件和诊断日志为准。

## 网络、隐私与版权

视频、光盘内容、字幕和输出默认只在本机处理。首次安装工具或模型需要联网；在线翻译和视觉 OCR 可能向用户选择的第三方服务发送字幕文字或字幕图像，视频文件默认不上传。API Key、第三方费用、数据留存和服务条款由用户直接负责。
